## Implemented scope
Seventeen searchable pattern cards link to `/patterns/[id]`: original prediction questions, misconception feedback, a manual state walkthrough, a transfer reflection and sourced product use. Each distinguishes documented implementation from illustrative product design. Reflections are page-local, not graded or account-saved.

`/practice` offers 20 native Python problems and a separately labeled 54-item external reference library. `/design` offers six guided exercises across system design, database design and architecture. Design drafts are browser-local with Markdown export.

## Acceptance
Wrong predictions receive relevant guidance without blocking exploration. Every pattern has a source, tradeoff and valid related practice target. Beginners receive definitions rather than unexplained jargon. No AI answer generation, fake mastery score or guarantee of interview success. Keyboard controls and mobile layouts are tested with browser journeys.
