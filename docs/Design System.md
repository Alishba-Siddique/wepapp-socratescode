## Identity
- Brand text: **socratescode**.
- Brand: #754934; canvas: #F9F8F6; ink: #131313.
- Instrument Serif for editorial headings; Manrope for UI; JetBrains Mono for code.
- Root Design.md's teal is superseded by the user's explicit brown brand choice.
- Use original Socrates artwork thoughtfully. Do not repeat a scene across the landing page or return to a generic hero text/image split.

## Learning interface
The app should feel related to the landing page without behaving like a marketing animation.
- Normal heading sizes: 32?48 px desktop, 28?36 px phone.
- Body text: 14?16 px with comfortable line height.
- Keep code, trace state, and the current question visually connected.
- No image over text, autoplayed lesson progression, giant headings, or disappearing copy.
- Use native scroll and clear focus rings. Respect reduced motion in the app.
- A user can proceed with keyboard only. Label every input.
- Prefer real progress and helpful empty states over decorative metrics.
- On phones, stack lesson and trace panes and keep stage navigation reachable.
