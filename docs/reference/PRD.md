# Product Requirements Document (PRD)
**Project Name:** SocratesCode
**Concept:** An open-source, anti-spoon-feeding pedagogical platform teaching core programming logic and problem-solving.

## 1. Problem Statement
The modern developer ecosystem has fostered a heavy dependency on AI auto-completion (LLMs, Copilots). This creates a generation of "syntax editors" rather than problem solvers. When these engineers face strict, logic-heavy technical interviews—especially Data Structures, Algorithms, and system design whiteboard sessions common in competitive markets—they freeze. Furthermore, traditional academic metrics (like GPA) often fail to reflect an engineer's true potential if they lack practical, independent problem-solving frameworks. 

## 2. Solution
SocratesCode acts as an AI-powered constraint engine. It actively refuses to write code for the user. Instead, it utilizes the PRIMM pedagogical framework (Predict, Run, Investigate, Modify, Make) and Socratic questioning to force the user to trace state, understand control flow, and build logic independently.

## 3. Target Audience
*   **Primary:** Working developers (1-3 years experience) who rely heavily on AI to ship features but struggle with pure logic building and suffer from imposter syndrome.
*   **Secondary:** Developers preparing for rigorous tech interviews that restrict AI usage.

## 4. Core Features
*   **Socratic Constraint Protocol:** An AI agent that analyzes runtime errors and outputs pedagogical questions instead of syntax.
*   **Interactive Visual Code Stepper:** A visual dry-run environment with a real-time trace table, forcing users to track variable mutations line-by-line.
*   **Gamified Independence Leaderboard:** A scoring system that ranks users based on their ability to solve puzzles with zero or minimal AI hints.
*   **Curriculum Matrix:** Bite-sized logic puzzles ranging from basic loop primitives to complex algorithmic abstractions.
